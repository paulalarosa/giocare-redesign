# Gio Care — Redesign (prévia)

Prévia visual do redesign do [giocare.app](https://giocare.app), sistema para médicos nutrólogos.
Direção visual **"Nascente"**: gradiente magenta→coral da marca sobre neutro vinho/amora,
tipografia editorial (Fraunces + Hanken Grotesk + IBM Plex Mono) e o protocolo ABCDEFS como
espectro de cor.

> Showcase estático para apresentação. O produto real (Next.js + Supabase + IA) roda em servidor;
> esta prévia é só a camada visual da landing e das telas internas.

## Rodar local

```bash
node server.mjs   # http://localhost:4321
```

Ou qualquer servidor estático apontando para a raiz.

## Estrutura

- `index.html` — landing
- `assets/tokens.css` — sistema de tokens "Nascente" (nomes espelham o app para portar direto)
- `assets/landing.css` — estilos da landing
- `assets/img/` — marca Gio Care
